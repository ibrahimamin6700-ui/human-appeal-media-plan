HUMAN APPEAL MEDIA PLAN — PWA APP
=================================

الريبو ده فيه تطبيق PWA لداشبورد Human Appeal Media Plan.

طريقة التشغيل:
1) انشر Google Apps Script كـ Web App.
2) انسخ رابط /exec.
3) افتح التطبيق والصق الرابط مرة واحدة.
4) التطبيق يحفظ الرابط على الجهاز.

الداتا تفضل Live من Google Sheets عن طريق Apps Script.

للتشغيل محليًا:
  npm start

للنشر على Cloud Run:
  deploy-cloud-run.sh
أو على ويندوز:
  deploy-cloud-run.bat

التطبيق يحتوي على:
- PWA قابل للتثبيت
- Human Appeal branding
- Online / Offline indicator
- Settings لتغيير رابط الداشبورد
- Service Worker
- Cloud Run / Firebase hosting files
